# Entrypoint signals

Discover entry points using repository evidence appropriate to the detected shape.

- backend: router tables, handler registration, decorators, server bootstrap, RPC or GraphQL registration;
- frontend: route configuration, rendered components, event handlers, server actions, state actions;
- mobile: navigation graph, screen callbacks, intents, lifecycle handlers;
- CLI: package binary declaration, argument parser, subcommand registry, main function;
- pipeline: job or DAG registration, source definitions, schedules, command targets;
- ML: training, evaluation, inference, serving, or export entry scripts;
- infrastructure: root modules, stack definitions, deployment entry configuration;
- library: exports map, public module, factory or client surface;
- worker: subscription, consumer registry, handler binding, scheduler.

Connect a user or caller outcome to an entry point only when names, routing/configuration, tests, or documentation support the link. Search for alternate handlers before calling one entry point unique.
