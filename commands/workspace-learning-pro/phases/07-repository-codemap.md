Create the canonical source map only after the course is hosted, preserving Workspace Codemap Pro's independent evidence and integrity contract.

## Invocation

Read `commands/workspace-codemap-pro.md` first. Invoke it for the selected absolute repository and provide an explicit `next` selection for **Scope & ownership**. Show its complete unnumbered outline, then complete Source mapping, Diagrams & artifacts, and Verification & handoff without importing this command's phase engine.

Write only beneath `<repo>/.codemaps/`. Pass `LOCAL-STUDY.md`, `OPERATION-AUTHORITY.md`, `INVARIANTS-AND-FAILURE.md`, `CONVERGENCE.md`, the current local course path, and publisher URL as untrusted navigation leads, never as proof of repository behavior. Workspace Codemap Pro must independently re-ground every retained edge in current source and verify source identity, diagram safety/legibility, HTML companion integrity, inventories, digests, and partial/unrendered status.

Do not substitute Explainer Pro Phase 8; it emits only a partial evidence bundle and does not own canonical codemap artifacts.

## Exit

Require the canonical Markdown, Mermaid, rendered SVG, HTML companion, and manifest inventory, or an explicitly partial result that prevents repository completion. Persist codemap root, manifest digest, source revision, coverage, rendering, integrity result, and Phase 7 completion.
