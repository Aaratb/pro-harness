# Phase 6 — Course Publication

Publish the verified Explainer Pro course as a reviewable the docs publisher document and prove the hosted bytes remain valid.

## Publication

Resolve and read the runtime `$docs_publisher` skill completely. Declare artifact type `report`; run its live guidelines and read its document schema and grounding rules.

Preserve the immutable Explainer `course.html`. Create an publisher-compatible copy beneath the same ignored Explainer root. Retain the course content and add only what the publisher contract requires: one title and H1, reader-theme integration, `summary`, `context`, `body`, `risks-or-caveats`, and `sources` sections, grounded citations, and self-contained assets. Do not invent content, weaken claim tiers, or hide course gaps.

Run the skill's validator as `report`. Discover create/pull syntax from the installed CLI help, publish with structured output, and capture document ID and URL. Pull the published version and run the same validator again. Compare local/published content digests when the CLI exposes equivalent body bytes; otherwise state the exact readback check performed.

The user's invocation explicitly authorizes publication for each completed repository. It does not authorize login, permission widening, unrelated updates, or publishing with unknown markers unless separately approved.

## Failure

On missing CLI/auth, validation failure, create failure, or readback failure, mark Phase 6 blocked and stop. Do not continue to the codemap as if the course were hosted.

## Exit

Persist publisher document ID, URL, local publication-copy digest, pulled digest/check, validation result, and Phase 6 completion. Update the repository learning index with the URL.
