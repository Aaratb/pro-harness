# Phase 9 — Causal Experiments

Read the causal-experiments reference when experimentation is needed. Preregister the prediction and show the smallest one-variable change before execution. Record actual output and the remaining explanations; a declared coupled dependency resolution set is the explicit multi-variable exception.

Eliminate only with an executed discriminating experiment or directly relevant archival evidence. Reasoning changes priority, not truth. `PROBE_ERROR` is not PASS or elimination; never run the same failed probe a third time without reassessing.

For several sufficient causes, reduced but nonzero failure after removing one factor is partial necessity, not refutation. Preserve the disjunctive explanation.

A justified `--bisect` requires a proven good point, explicit authority and a throwaway worktree. An exposing commit is change evidence, not root cause. Data/configuration/traffic/time axes are not code bisect.

Gate: cause is discriminated, or remaining uncertainty and its safe resolution are stated. Three failed corrections trigger model reassessment, not a fourth patch.
