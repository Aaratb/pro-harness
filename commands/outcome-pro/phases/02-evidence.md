# Phase 2 — Evidence

Prioritize collectable gaps that could change the decision; reuse sufficient dashboards, metric definitions, telemetry, queries and exports. Load `skills/outcome-evidence-audit/SKILL.md`; use the evidence focus when its routing trigger applies. For new measurement/query design, select the relevant reference from `skills/outcome-analysis/SKILL.md`, not every domain skill.

Reuse checked evidence and calculations across phases only with unchanged source bytes, definitions, scope and cutoff; refresh affected checks/claims when these change. Reuse never replaces a challenger's original-source checks or final report validation. Apply the method's decision sensitivity before expanding collection: stop at nonmaterial gaps, authority limits or immature windows, and disclose them. Missing required comparative evidence still means insufficient evidence, never a waived gate.

## Collect, request, or arrange measurement

1. **Data exists:** state source/environment/tenant, exact numerator/denominator/unit, cohort/exposure, baseline/observed windows and reason needed. With scoped read authority, collect now through existing connectors or documented read-only APIs/queries. Prefer aggregate views or replicas. Bound timeout, scanned volume/cost and output size using source-specific limits; server-side aggregate, use least privilege and suppress sensitive small cohorts. Read-only queries can overload production. Stop on permission failures, unexpected sensitive data or scope expansion; never invent generic safe limits.
2. **Access missing:** specify exact source, aggregate query/export and scoped access or sanitized export needed. Do not silently install integrations, broaden credentials or substitute unrelated telemetry. The blocked branch remains unexecuted; continue useful assessment from available evidence, never substitute zero.
3. **Metrics missing:** identify the decision measurement could change, minimal event/metric, calculation, unit, exposure/cohort, existing instrumentation site, privacy/cardinality limits, owner, data-quality check and collection window. Suspected broken telemetry goes to Review first. Genuinely missing instrumentation uses Feature and existing build/review/release gates when separately authorized. Reuse `observability-by-design` if needed. Do authorized work without duplicate approval, but do not turn this command into a second builder. Shared dashboard/alert/config writes also require scoped authority. Verify event-to-aggregate flow, deduplication and absence of sensitive fields before claiming setup complete.
4. **Record:** coordinator saves new minimized snapshots and collection method/query definition, retrieval time, exposure coverage, limitations and errors beneath `artifact_root`; pre-existing evidence roots stay read-only. The approved evidence root may be that run's snapshot directory, never an invented output workspace. New telemetry observes only after going live; no fabricated baseline or retroactive backfill. A defensible historical equivalent requires matching definitions. Schedule reassessment only when requested through the host's existing automation mechanism.

`collect-evidence` is a follow-up label, not a new fetch engine or recurring monitor. Missing authority or immature windows can yield an honest insufficient-evidence assessment; no indefinite polling or positive-result loop.

## Source-to-claim gate

Trace exact original source field/passage → inputs and executed arithmetic/output → unit/population/exposure/window → strongest supported conclusion. Verify original target/sample-policy/definition provenance as well as observed values. Reconcile discrepancies or retain explicit gaps. Unknown is `null`, never zero. Preserve every primary outcome and accepted guardrail; favorable aggregates cannot erase segment harm.

Coordinator independently checks returned evidence against originals. Load `skills/outcome-pro/references/calculation-proof.md` before any local evidence-file read, including qualitative evidence. Compatible JSON sources can use a coordinator-written optional worksheet and `verify-outcome-calculations.mjs` once a comparative report exists. Equivalent reproducible read-only proof is allowed for other authentic formats/math. Check every material number; a physical worksheet is optional. Arithmetic and hashes do not prove source truth, eligibility or causal meaning.

Complete with source quality, comparability/maturity, checked calculations, collection/setup completed or blocked and remaining gaps. Evidence-only work stops here without an outcome verdict.
