# Phase 4 — Independent Challenge

Read `roadmap-independent-challenge`; use its deeper lenses only for the claims at stake. Give a genuinely fresh `roadmap-analyst` invocation the original authorized evidence, constraints and candidate without prior author rationale or reviewer conclusions. When fresh isolation is unavailable, disclose a limited self-check or awaiting-challenge status; never fabricate independence.

Reconstruct the strongest case, then test rival explanations, mechanism fit, source scope, portfolio completeness, economic overlap/sensitivity, note fidelity and capacity feasibility as applicable. A valid objection links source to the faulty inference and its decision consequence. No-material-objection is valid when the reasoning survives; no mandatory finding count or unanimity vote.

If an original customer/strategy claim needs a distinct upstream check, use the existing Customer challenge mode without duplicating the same review. Reconcile one critique, response and synthesis; revise affected headlines when evidence demands it. Preserve human decisions and dissent. A new material execution or note claim can return here for a bounded check without redoing unrelated work.
