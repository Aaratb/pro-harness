# Phase 4 — Research Records

Use `customer-research-records` for actual supplied notes, transcripts, exports or corrections. Skip new record processing when an existing checked record set is sufficient. No interviews or participant actions are performed by this phase.

Keep account/person, contact attempt, conversation, episode and source identities distinct. A planned question or consent script is not evidence of execution. Record asked/skipped/unknown, usable negative versus missing/damaged response, exact instrument/version and pre/post-concept context where known. Quotes require inspected wording and attribution; notes describing recordings remain notes.

Preserve original language, damaged-span uncertainty, source families and actual permission/commitment events. Do not convert a promised follow-up into a completed action. Use existing restricted identity references only when needed; never append raw contact details to shared artifacts.

For corrections, preserve old evidence and show affected question counts, membership, interpretations and supplied dependent artifacts. Recompute only authorized quantities; the static worker requests arithmetic rather than executing it. The coordinator owns permitted edits to derived records, visibly replacing stale current headlines without claiming unperformed downstream changes. Return a proportionate faithful record set, not a compulsory database.
