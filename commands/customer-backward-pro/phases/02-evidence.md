# Phase 2 — Evidence & Access

Use `customer-evidence-audit` for supplied material. Add `customer-research-access` only for a real source/access question; `--capability access` does not silently run the audit method. Resolve only permitted evidence and preserve the actual inspected medium, source families, completeness, restrictions and missing originals.

Check source-to-claim support, collection context, prompt/exposure bias, duplicated people/events, question-specific denominators, contradictions and correction impact. A derivative summary is not new corroboration. Retain useful episodes even when one span is damaged; narrow only the affected inference.

Prefer supplied exports/text. For explicitly requested public competitor/market evidence, the coordinator uses the existing Firecrawl capability first; Exa is a targeted supplement when useful, not a compulsory second pass. Read the selected capability contract and actual tool documentation; bind public query/URLs and limits, record retrieval/source scope, and never submit private records. Workers do not browse. Missing provider access permits an offline result or exact evidence request, not installation.

Warehouse, contact, recording, transcription/transfer and publication requests remain proposals; the optional inert operation preflight does not execute them. Return which evidence can support which claims, what is uninspected, any approved public acquisition actually completed, and the next useful learning. No new source needs to be collected when existing evidence suffices.
