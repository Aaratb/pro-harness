# Diagnostic replay results — 2026-09-05

## Outcome

The richer instructions did not demonstrate a broad decision-quality improvement on this small probe set. Product, engineering and QA reached the fixed rubric ceiling in both arms. Design improved by one point across three trials, which is insufficient evidence of a general improvement. This does not erase the separately observed loss of methods and missing skill bindings; it shows that explicit, context-rich diagnostic prompts can already elicit strong baseline answers.

- Baseline median elapsed time: 31.14 seconds; candidate: 34.31 seconds. Ranges: 29.63–60.95 and 30.85–45.61 seconds respectively. These include startup/provider variability and are not workflow latency claims.
- Reported baseline usage: 360,982 input tokens, including 98,176 cached, and 6,968 output tokens. Candidate: 367,036 input tokens, including 129,280 cached, and 6,926 output tokens. Input counts include CLI-injected context; dollar cost was unavailable.
- Baseline response lengths: 400–447 whitespace-delimited words. Candidate: 401–451. Candidate engineering trial 3 exceeded the 450-word budget by one word; trial 2 used exactly 450 despite the prompt saying “under 450.” Both were retained and scored.
- Runtime: codex-cli 0.153.2, identical CLI defaults, user configuration and repository rules ignored, ephemeral read-only sessions. Exact backend model identity was not available in retained metadata; this limits reproduction.
- Before authorization, infrastructure/permission failures produced no valid scored response. Hosted transfer proceeded only after explicit user approval. Payloads contained skill instructions and synthetic cases, not pilot/customer data.

## Interpretation and remaining checks

These are diagnostic, non-held-out tasks with explicit hazards and theme overlap with skill examples. Rubric judging was arm-blind and independently performed, but there is no inter-rater reliability estimate or statistical generalization. The apparent ceiling is a reason to improve future evaluation difficulty, not to claim universal equivalence or improvement.

Scores bind the eight frozen replay skill texts. Four additional generation/specification skills and dispatch changes received structural checks, not isolated behavioral evaluation. After the replays, a small reviewed editorial change allowed product review to report no material unknowns instead of inventing one; that wording was not replayed.

Canonical catalog/command validation and the full test suite passed (259 tests), including temporary Claude/Codex/Cursor adapter generation carrying the new bindings. This does not establish actual client discovery or permission enforcement. Live adapters and the active pilot were not modified. A real feature exercise with verified specialist dispatch, rendered alternatives, and executed behavioral QA remains the relevant end-to-end test.
