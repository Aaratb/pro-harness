Audit all sixteen methods against actual research decisions, then run two fresh-context attempts for each of seven synthetic cases. Freeze runtime files before attempts. Actors receive only their case and the frozen command/methods, not rubrics, audit conclusions or previous answers. They use supplied evidence only; no customer contact, live providers, production queries, installations or product mutations. Local arithmetic is permitted where needed. A test-only response record lives in an explicit temporary output root; no simulated research execution is invented.

A separate connected journey exercises evidence → understanding → fit/strategy/validation → fresh independent challenge → reconciliation. The challenger receives original evidence and the candidate, not the author's private rationale or a prior review. Reuse the existing two roles and current methods; no new runtime orchestration system.

Independently judge observed answers against `rubrics.json`, withholding audit opinions and other trial scores. Score each criterion 0 absent/incorrect, 1 partial/generic, 2 concrete/correct. A pass needs at least 8/10, no zero and no critical failure. Keep all attempts, including partial/tool-limited results. These thresholds are diagnostic criteria, not calibrated research-quality probabilities.

Change instructions only for a demonstrated behavior failure or concrete source-level contradiction. Rerun affected cases with fresh actors against the patched snapshot; do not silently replace failed trials or keep retrying until green. Add focused structural guards only for real routing/invariant changes, never call phrase matching proof of judgment. Run the existing validators and test suite after edits.
